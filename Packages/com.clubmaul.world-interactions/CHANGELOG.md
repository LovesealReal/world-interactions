# Changelog

All notable changes to the Club Maul World Interactions package are documented in this file.

## [1.0.0] - 2026-07-08

### Added

- Initial release as a preset on top of the World Interactions core
  (`com.loveseal.world-interactions`).
- Prefab pre-configured for the Staff Scanner V2 ecosystem: Slow (`ClubMaul/Slow`),
  Rumble (`ClubMaul/Rumble`), and staff detection (`ClubMaul/Scanner/Show`,
  legacy `ClubMaulShow`, standard `WI/Presence`).
- Menu items: Tools → Club Maul → Initialize World Interactions, and
  GameObject → Club Maul → World Interactions.
